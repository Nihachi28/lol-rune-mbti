## 1. 项目概述

### 1.1 项目背景

1. 英雄联盟**嚎哭深渊（海克斯大乱斗）** 作为全民休闲竞技模式，玩家行为特征极强，无对线、无运营、全程抱团团战，玩法与召唤师峡谷完全割裂；

2. B站视频**BV1JnX6B1Ede《海克斯大乱斗的不同主义》** 精准刻画了雪球莽夫、墙角POKE、KDA苟活等经典乱斗玩家形象，评论区玩家高度共鸣，形成专属圈层梗文化；

3. 经典MBTI测试的**二分法判定、雷达图可视化、字母/标签化人格分类**模式，可完美适配乱斗玩家行为，转化为趣味测试产品，满足玩家自测、玩梗、社交分享需求。

### 1.2 项目定位

面向英雄联盟海克斯大乱斗玩家的**非专业趣味人格测试网站**，抛弃严肃心理测试属性，全程采用戏谑化、黑话化表达，复刻MBTI测试交互逻辑，打造专属「海斗人格」标签体系。

### 1.3 项目目标

1. 搭建**大乱斗专属5大二分维度测试体系**，覆盖所有乱斗玩家行为画像，无盲区、无无效组合；

2. 实现「答题→自动计分→雷达图生成→人格标签展示」全流程线上化；

3. 网站视觉贴合嚎哭深渊风格，内容100%匹配B站视频及评论区玩梗语境；

4. 支持结果图片生成、社交平台分享，满足玩家传播需求；

5. 轻量化落地，适配手机/PC双端，操作极简无门槛。

## 3. 核心测试体系设计（核心业务规则）

### 3.1 底层逻辑：MBTI二分法适配

完全沿用MBTI经典**二分法判定规则**，无中间值、无模糊区间，每个维度仅二选一，通过题目计分确定最终倾向，适配雷达图绘制与人格分类。

### 3.2 五大核心二分维度（戏谑版·乱斗专属）

共5大独立维度，10个对立倾向，无逻辑重叠，覆盖乱斗所有核心行为，适配10轴雷达图绘制：

|维度编号|维度名称|二分对立倾向|戏谑化判定标准|
|---|---|---|---|
|1|雪球冲锋执念|冲脸莽夫 🦁 / 缩头仓鼠 🐹|雪球必飞开团 / 雪球捏到游戏结束|
|2|技能释放态度|狂甩机器 💥 / 大招收藏家 🔒|见人就甩技能清场 / 大招只留到翻盘用|
|3|风险承担觉悟|敢死开团手 ✊ / KDA守财奴 💰|肉身开团卖自己 / 苟到最后绝不送头|
|4|输出距离偏好|贴脸战神 👊 / 墙角POKE怪 🎯|贴脸肉搏输出 / 蹲地图角落远程消耗|
|5|游戏核心心态|乐子至上 😂 / 赢麻党 🏆|输赢无所谓操作要帅 / 这把必赢不赢睡不着|
### 3.3 计分与维度判定规则

1. **题目设计**：每个维度3道二分选择题，总计**15道题**，每题仅A/B两个选项；

2. **计分规则**：每题计1分，单个维度总分3分，某一倾向得分更高则判定为该维度最终倾向；

3. **结果锁定**：纯二分判定，无「平衡型」，直接确定5个维度的最终倾向；

4. **数据适配**：维度得分直接映射雷达图坐标，无需复杂换算。

### 3.4 雷达图可视化规则

1. **轴数设计**：10个坐标轴，对应5组对立倾向，均匀分布；

2. **刻度规则**：中心为0分（无倾向），外围为3分（满倾向）；

3. **绘制逻辑**：根据各维度得分标记坐标点，连接形成闭合蛛网图；

4. **视觉效果**：倾向越明显，雷达图凸出越夸张，直观体现「莽夫/苟命」「乐子/上分」等核心特征。

## 4. 人格分类体系（海斗经典人格）

基于5大维度组合，理论上可形成2⁵=32种人格（每个维度2种倾向，无重叠无矛盾），初期仅保留16种核心人格，核心理由如下：1. 优先筛选玩家共鸣最强、行为最典型的组合，剔除逻辑矛盾或现实中几乎不存在的组合（如“既冲脸莽夫又缩头仓鼠”“既敢死开团又极致苟命”这类完全对立的倾向组合）；2. 初期简化认知成本，方便用户快速理解和传播；3. 预留扩展空间，可根据需求补充完整32种组合，且补充组合均符合乱斗真实玩家行为，无无效搭配。本次已补充完整32种人格，均遵循“逻辑自洽、贴合乱斗场景、戏谑玩梗”原则，覆盖所有合理组合，完美匹配2⁵=32种维度组合逻辑，命名为「XX主义」，匹配B站视频调性，每个人格包含：标签、行为画像、本命英雄：

    - 后台实时统计各维度得分，自动判定维度倾向；

    - 动态生成10轴乱斗人格雷达图；

    - 匹配本命英雄推荐，附带趣味吐槽；

    - 雷达图居中展示，视觉突出。

6. **社交分享模块**

    - 支持生成结果海报图片（含雷达图+人格标签）；

    - 支持保存图片到本地。

    - 重新测试按钮；
