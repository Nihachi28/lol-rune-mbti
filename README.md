# 海斗人格测试 - 海克斯大乱斗MBTI

一个基于MBTI二分法的英雄联盟海克斯大乱斗趣味人格测试网站。

## 项目简介

这是一个面向英雄联盟海克斯大乱斗玩家的非专业趣味人格测试网站，抛弃严肃心理测试属性，全程采用戏谑化、黑话化表达，复刻MBTI测试交互逻辑，打造专属「海斗人格」标签体系。

## 功能特性

- ✨ **5大测试维度**：雪球冲锋执念、技能释放态度、风险承担觉悟、输出距离偏好、游戏核心心态
- 🎯 **32种人格结果**：基于5个维度的组合，生成32种不同的乱斗人格类型
- 📊 **雷达图可视化**：直观展示你在各个维度上的倾向
- 🎮 **15道趣味测试题**：贴近大乱斗实际游戏场景，戏谑玩梗风格
- 💾 **结果保存**：支持将测试结果保存为图片
- 📱 **响应式设计**：完美适配手机和电脑端
- 🎨 **精美UI设计**：采用嚎哭深渊蓝紫暗黑风格，玻璃拟态效果

## 技术栈

- **前端框架**：React 18
- **样式框架**：Tailwind CSS
- **构建工具**：Babel Standalone
- **图表库**：Canvas API（自定义雷达图）

## 快速开始

### 方法一：直接打开（推荐）

直接在浏览器中打开 `index.html` 文件即可开始使用：

```bash
open index.html
```

### 方法二：使用本地服务器

如果你需要使用本地服务器运行：

```bash
# 使用Python启动简单HTTP服务器
python -m http.server 8000

# 或使用Node.js的http-server
npx http-server
```

然后在浏览器中访问：`http://localhost:8000`

## 使用说明

1. **开始测试**：点击首页的"开始测试"按钮
2. **回答问题**：逐题回答15道选择题，选择最符合你游戏习惯的选项
3. **查看结果**：完成测试后，系统会自动计算并展示你的乱斗人格类型
4. **保存分享**：可以保存结果图片，分享给朋友
