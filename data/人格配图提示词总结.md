# 32种海斗人格配图提示词总结

## ✨ 设计思路

基于LOL英雄亚索的形象，结合32种海斗人格的独特性格特征，为每种人格设计了专属的配图生成词。所有提示词遵循统一的低多边形几何风格，通过服饰、道具、神态、配色的差异化，展现每种人格的独特个性。

---

## 🎨 基础风格规范

所有32种人格共享以下基础风格参数：

```
基础风格描述：
- 角色原型：LOL英雄亚索
- 艺术风格：低多边形几何风格
- 表现手法：矢量插画
- 线条特征：锐利的棱角边缘
- 上色方式：扁平色块上色
- 色彩特征：鲜艳纯色
- 背景要求：干净纯白背景，无文字
- 设计感：卡通现代感，强设计感
- 质量要求：8K超高清，无噪点，无杂色，画面干净通透
```

## 🎯 设计亮点

### 1. 性格视觉化
每种人格通过服饰、道具、神态的组合，直观展现性格特征：
- **雪球人柱力**：红色武士铠甲 + 巨大雪球 → 狂热执念
- **墙角泽拉斯**：蓝色法师长袍 + 狙击姿态 → 阴郁专注
- **乐子人**：紫色炫酷时装 + 小丑面具 → 嬉皮笑脸

### 2. 色彩语义化
通过主色调传达性格情感：
- **红色/橙色**：热血、冲动、勇敢（冲锋开团型）
- **蓝色/绿色/紫色**：冷静、距离、精准（POKE输出型）
- **彩虹/粉色/灰色**：娱乐、随性、不拘一格（整活娱乐型）
- **金色/银色/白色**：精致、贵气、稳重（KDA保命型）

### 3. 道具符号化
每个道具都有明确的符号意义：
- **雪球**：雪球人柱力的执念象征
- **魔法飞弹**：远程POKE的输出象征
- **小丑面具**：乐子人的娱乐象征
- **数据面板**：KDA战神的成就象征

### 4. 神态情感化
通过表情和眼神传达情感：
- **狂热癫狂**：雪球人柱力的执着
- **阴郁专注**：墙角泽拉斯的冷静
- **嬉皮笑脸**：乐子人的轻松
- **狡黠得意**：收集者K头狗的得意

## ⚙️ 质量控制建议

### 1. 提示词优化
如需微调提示词，注意保持：
- 低多边形风格一致性
- 亚索角色特征保留
- 配色方案协调统一
- 神态表情生动自然

### 2. 尺寸规范
建议统一使用：
- **尺寸**：1024x1024 或 512x512
- **格式**：PNG（支持透明背景）
- **质量**：8K超高清，无压缩

### 3. 背景处理
- 保持纯白背景（#FFFFFF）
- 无任何文字、水印
- 无噪点、杂色
- 画面干净通透

### 4. 风格统一
- 所有角色均为亚索造型
- 统一低多边形几何风格
- 统一扁平色块上色
- 统一锐利棱角边缘
